T6 · 3-column (ticks · detail · actions)

  • Column 1 (200 px): chronological tick list, newest on top. Skip / error rows tinted so the recent 403 cluster is visible at a glance.
  • Column 2 (flex): selected tick's full conversation — user prompt, thinking, tool calls + results, final summary. Same chat style as T1, scoped to one tick.
  • Column 3 (320 px): the action cards that tick produced. Hand-in-glove with column 2: you read what Maestro decided, then see (and Approve / Edit / Snooze) the proposals next to it.
  • Empty / skipped ticks render an inline banner in column 2 ("Tick 25 skipped — idle gate. No plan written.") and an empty placeholder in column 3.
  • Tradeoff: action cards are narrower than the dedicated Actions tab — long prompts wrap to 3–4 lines. The trade buys you context: you can't accidentally Approve without seeing the reasoning behind it.

T2 · Tick accordion

  • One collapsible row per tick (incl. error/skip rows). Default-open the most recent successful tick; everything else collapsed.
  • Failed ticks distinguished by colour + label so the noisy 403 string of recent ticks is glanceable, not buried.
  • Inside an expanded row: same chat layout as T1, but scoped to that tick. Easier mental model for "what did this tick do?"
  • Tradeoff: requires a click to read; if you usually want the latest, T1 is one less interaction.
